# 知识蒸馏训练流程解析（train_distillation.py）

> 让一个**小模型（学生）**模仿**大模型（教师）**的输出分布，用更少参数达到接近大模型的效果。

---

## 一、什么是知识蒸馏？

```
教师模型（大，768维 × 16层）
    │
    │  输出概率分布（"软标签"）
    ▼
学生模型（小，512维 × 8层）
    │
    │  同时学习：① 真实标签 ② 教师的概率分布
    ▼
更小但更聪明的模型
```

普通训练只看"正确答案"（硬标签：下一个 token 是"天"），蒸馏额外让学生学教师的"思考过程"（软标签：60% 可能是"天"、20% 是"气"、10% 是"候"...）。

---

## 二、与预训练/微调的差异总览

| 维度 | 预训练/微调 | 知识蒸馏 |
|------|-----------|---------|
| **模型数量** | 1 个 | **2 个**（教师 + 学生） |
| **损失函数** | 交叉熵 | **交叉熵 + KL 散度**的加权和 |
| **额外超参** | — | `alpha`（CE 权重）、`temperature`（蒸馏温度） |
| **数据集** | 各自的 | 用 SFTDataset（与微调相同） |
| **训练循环** | 标准流程 | 需要额外跑教师模型的前向传播 |
| **其余流程** | — | 初始化/AMP/DDP/保存等**完全一致**，略过 |

---

## 三、核心差异详解

### 3.1 两个模型的初始化

```python
# 学生模型（可训练）
lm_config_student = MiniMindConfig(hidden_size=512, num_hidden_layers=8)
model, tokenizer = init_model(lm_config_student, args.from_student_weight, device=args.device)

# 教师模型（冻结，仅推理）
lm_config_teacher = MiniMindConfig(hidden_size=768, num_hidden_layers=16)
teacher_model, _ = init_model(lm_config_teacher, args.from_teacher_weight, device=args.device)
teacher_model.eval()
teacher_model.requires_grad_(False)  # 冻结所有参数，不计算梯度
```

> 教师模型更大（768 维 × 16 层 vs 学生的 512 维 × 8 层），且始终处于 eval 模式，不参与训练更新。

### 3.2 蒸馏损失函数（核心）

```python
def distillation_loss(student_logits, teacher_logits, temperature=1.0, reduction='batchmean'):
    # 教师的软概率（用温度"软化"分布，no_grad 不算梯度）
    with torch.no_grad():
        teacher_probs = F.softmax(teacher_logits / temperature, dim=-1).detach()

    # 学生的对数概率
    student_log_probs = F.log_softmax(student_logits / temperature, dim=-1)

    # KL 散度：衡量两个分布的差异
    kl = F.kl_div(student_log_probs, teacher_probs, reduction=reduction)

    # 乘以 T² 补偿温度缩放带来的梯度缩小
    return (temperature ** 2) * kl
```

**温度（Temperature）的作用：**

```
temperature = 1.0（正常）:
  教师输出: [0.90, 0.05, 0.03, 0.02]  ← 分布很"尖"，几乎只有一个答案
  学生能学到的信息有限

temperature = 1.5（软化）:
  教师输出: [0.60, 0.18, 0.12, 0.10]  ← 分布更"平"，暴露了更多"暗知识"
  学生能学到：第2、3、4个候选也有一定概率，不只是死记硬背第1个
```

> 温度越高，概率分布越平滑，教师传递的信息越丰富。推荐范围 1.0-2.0。

### 3.3 总损失的计算

```python
# 1) 学生模型前向传播
res = model(input_ids)
student_logits = res.logits[..., :-1, :].contiguous()

# 2) 教师模型前向传播（no_grad，不消耗梯度显存）
with torch.no_grad():
    teacher_logits = teacher_model(input_ids).logits[..., :-1, :].contiguous()
    # 教师词表可能更大，截断到和学生一致
    teacher_logits = teacher_logits[..., :vocab_size_student]

# 3) 真实标签的交叉熵损失（CE Loss）
ce_loss = F.cross_entropy(student_logits.view(-1, V), shift_labels.view(-1), ignore_index=-100, reduction='none')
ce_loss = torch.sum(ce_loss * loss_mask) / loss_mask.sum()

# 4) 蒸馏损失（KL Loss）—— 只对有效 token 计算
distill_loss = distillation_loss(
    student_logits[loss_mask == 1],   # 只取有效位置
    teacher_logits[loss_mask == 1],
    temperature=temperature
)

# 5) 总损失 = α × CE + (1-α) × KL
loss = alpha * ce_loss + (1 - alpha) * distill_loss
```

**alpha 参数的含义：**

```
alpha = 1.0 → 纯 CE，等于普通微调（不蒸馏）
alpha = 0.0 → 纯 KL，完全跟教师学
alpha = 0.5 → 各占一半（默认值，平衡真实标签和教师指导）
```

### 3.4 loss_mask 的构造

```python
loss_mask = (labels[..., 1:] != -100).float()
```

> 与 SFT 一样，只对"助手回复"部分计算损失。蒸馏 loss 也只在有效 token 上计算，避免在 padding/user 部分浪费计算。

## 四、关键超参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `student_hidden_size` | 512 | 学生模型维度 |
| `student_num_layers` | 8 | 学生模型层数 |
| `teacher_hidden_size` | 768 | 教师模型维度 |
| `teacher_num_layers` | 16 | 教师模型层数 |
| `alpha` | 0.5 | CE 权重（总损失 = α×CE + (1-α)×KL） |
| `temperature` | 1.5 | 蒸馏温度（越高分布越软） |
| `learning_rate` | 5e-6 | 学习率 |
| `epochs` | 6 | 训练轮数 |
| `from_student_weight` | `full_sft` | 学生初始权重 |
| `from_teacher_weight` | `full_sft` | 教师初始权重 |

## 五、训练流程图

```
每个 step:
  input_ids, labels ── 搬到 GPU
         │
    ┌────┴────┐
    ▼         ▼
 学生模型   教师模型(frozen)
    │         │
    ▼         ▼
student_logits  teacher_logits
    │         │
    ├─────────┤
    ▼         ▼
  CE Loss   KL Loss(temperature 软化)
    │         │
    └────┬────┘
         ▼
  总 loss = α × CE + (1-α) × KL
         │
         ▼
  backward → clip → step（只更新学生）
```
